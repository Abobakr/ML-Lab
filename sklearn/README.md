# Scikit-learn Track

The scikit-learn track demonstrates classical machine learning through compact, reproducible black-box examples. It includes regression, clustering, classification, preprocessing, validation, tuning, ensembles, PCA, and model persistence. Deep-learning and transformer lessons retain their specialist libraries.

Run a lesson from the project root:

```bash
python sklearn/01_linear_regression.py
```

Lessons `01`-`15` cover the core algorithms. Lessons `16`-`20` cover production-minded practice: preprocessing pipelines, cross-validation, hyperparameter search, gradient boosting, and saving/loading models.
