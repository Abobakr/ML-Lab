# TensorFlow Track

The TensorFlow track demonstrates neural-network workflows with Keras, including linear regression, ANN, RNN, CNN, and neural sentiment classification. Classical algorithms such as K-Means, KNN, SVM, Naive Bayes, random forests, PCA, validation, and tuning remain backed by scikit-learn because TensorFlow does not provide equivalent native estimators. The transformer lesson uses Hugging Face Transformers.

Run a lesson from the project root:

```bash
python tensorflow/03_ann_mnist.py
```

Lessons `01`-`15` cover the core algorithms. Lessons `16`-`20` cover preprocessing, validation, tuning, gradient boosting, and model persistence.
